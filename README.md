I developed a database to analyse Hotel Booking Data using SQL and visualized the data using Power BI.
The graphs represented in Power BI help us to answer some questions stakeholders might have about their hotels. 
The most important question to ask is whether revenue is increasing by year, since there are two hotel types in the data, I have segmented the hotels by type and
displayed them using a line graph and donut chart.
Other questions like the need to increase our parking space has also been explored. I have depicted the the total number of parking spaces and calculated the 
parking percentage. The data sugests a total of 2.36% of parking spaces being used.
Other important measures such as revenue, average daily rate and percentage of discount afforded have also been depicted.
